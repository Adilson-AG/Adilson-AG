# 💼 Projetos em destaque

## 🎨 Editor Gráfico

Desenvolvimento de um editor gráfico utilizando **React** e **Fabric.js**, voltado para criação de materiais promocionais.

Entre as funcionalidades implementadas estão:

* Manipulação de imagens em alta resolução
* Sistema de camadas
* Máscaras (Clipping)
* Undo / Redo
* Persistência completa do estado do editor
* Exportação otimizada
* Controle de DPI
* Reamostragem de imagens utilizando algoritmo de Lanczos
* Otimizações de renderização para melhor qualidade visual

---

## 📡 Plataforma IoT com ESP32

Projeto completo para monitoramento e automação utilizando ESP32.

Recursos desenvolvidos:

* Configuração via Bluetooth Low Energy (BLE)
* Comunicação Wi-Fi
* AsyncWebServer
* Armazenamento em SPIFFS
* Integração com Firebase
* Dashboard Web
* Monitoramento em tempo real
* Registro histórico de sensores
* Atualização remota de configurações
